# PestHalt (pesthalt.us)

Nationwide pest control referral website. Static HTML generated by Python.

- `tools/` — generator (`build.py`, `core.py`, `content/`) and `audit.py`
- `public/` — built site (Cloudflare Pages build output directory)
- `functions/api/lead.js` — contact form handler (Resend)

Build and audit: `python3 tools/build.py && python3 tools/audit.py`

See `STATUS.md` and `RECORD_REGISTER.md` for progress.
